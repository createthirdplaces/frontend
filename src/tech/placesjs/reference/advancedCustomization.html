Advanced customization

These classes can be used or extended to provide customized functionality.

  • ApiLoadAction : Load data into a store from an API
  • CustomLoadSignal : Load data into a store with a custom load function.
  • DataStoreSignal :Combine data from multiple stores.
  • ItemUpdater : Update presentation component template with one data item
  • ListUpdater : Update presentation component template that has a list of items.
  • ShadowDOMComponent : Component inside shadow DOM
  • StaticComponent : Static component with event handlers.
  • TemplateItem : Parses HTML templates and connects them to state management.
