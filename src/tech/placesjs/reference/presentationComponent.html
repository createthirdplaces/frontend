Components

Components are created through the PresentationComponent.js class, which supports dynamic state and templating.

Creating a presentation component

Attributes

  • data-store: Name of store used by component
  • data-template: Enables templating.
{{>places-js/reference/PresentationComponent/htmlExample}}

Important notes

  • A presentation component with templating enabled must have a single top level child node.
  • The data-store attribute refers to the name of of the store used. See the Data Management page for an example of how to configure state.
  • If a store is defined using the data-store attribute, it should be imported before the customElements.define call.
