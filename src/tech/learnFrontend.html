Learning tips

  1. Add the following code to a .html file and save it.
    2. {{>tech/learnFrontend/startExample}}
  2. Open the file browser on your computer, navigate to the file, and then right click on it.
  3. CLick the option that opens the file in the browser, and view the page. You should see a popup alert that says "Hello World"

While there are disadvantages of including code for all three languages in a single file, it does minimize the initial learning curve. You can also open a file without needing to setup a dedicated server or custom build.

Don't use third party libraries or frameworks when learning

While third party tools are useful, they also obscure basic concepts and inhibit foundational learning. Also, having knowledge of fundamental concepts will help you evaluate third party tools and make sure you know how to use them effectively.

Avoid all use of LLMs such as ChatGPT or Claude when learning

LLMs interfere with the learning process by pushing you towards shortcuts and solving problems you should figure out on your own. LLMs are also very addictive and will probably push you away from trying to learn. If you are stuck, email gulu@createthirdplaces.org or look at the links below.
